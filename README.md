# Roblox Decals Bypass Tool 🚀

A lightweight Python application with a graphical user interface (Tkinter) and Pillow, designed for automated image processing tailored for Roblox decal upload requirements.

---

## 🛠 Features
* **Simple & Intuitive UI:** Clean minimalist interface using the `clam` theme.
* **Automated Transformation:** Centers images, adjusts canvas sizes, and applies multi-layered processing (blur, grayscale, brightness adjustments).
* **Noise Generation:** Adds random pixel noise to modify the image's digital footprint.
* **Rescaling:** Exports the final image at a custom dimension (`6500x300`).
